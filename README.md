# JavaScript: Полное руководство — Интерактивный конспект

> Interactive single-file HTML study companion **in Russian** for *JavaScript: The Definitive Guide* by David Flanagan (7th edition) — 17 chapters with syntax-highlighted code examples, progress tracking, dark/light theme, and formatted personal notes with view/edit toggle.

## Features
- 🇷🇺 Fully in Russian
- 17 chapters covering JS fundamentals to advanced topics
- Syntax-highlighted code examples per chapter
- Personal notes with **Markdown rendering** and edit mode
- Progress tracking saved in `localStorage`
- Dark / Light theme toggle
- Keyboard navigation (← → Escape)
- Fully offline — single `.html` file, no dependencies

## Usage
Simply open `js_flanagan_final.html` in any modern browser — no server or install required.

## Contents
Chapters range from *Lexical Structure* and *Types & Variables* through *Async JavaScript*, *Metaprogramming*, *Browser APIs*, *Node.js*, and *Modern Tooling* (TypeScript, Vite, Jest).

## Stack
Pure HTML · CSS · Vanilla JavaScript
